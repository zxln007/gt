下载客户端

        
免安装单文件,下载即用;服务端与客户端为同一二进制,Release 直链来自 GitHub。


        

          

            Linux / macOS 一键安装
            POSIX sh · 自动识别架构 · 含校验
          

          

            curl -fsSL https://gtunnel.dev/install.sh | sh
            
          

          
脚本自动检测系统与 CPU 架构,从 GitHub Release 拉取对应二进制并安装到 /usr/local/bin(无权限时为 ~/.local/bin)。可用 GT_VERSION 锁定版本、GT_REPO 切换发行源;Release 附带 checksums.txt 时自动执行 sha256 校验。
