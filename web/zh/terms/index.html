服务条款

最后更新:2026-08-31

本条款约束你对 G-Tunnel 托管服务的使用,包括运营于 gtunnel.dev 的中转服务器、账号控制台(console.gtunnel.dev)、发布于 *.app.gtunnel.dev 下的 HTTP 端点、中转 TCP 端口,以及桌面客户端的分发。开源客户端与服务端软件本身按 GitHub 仓库中的相应许可证提供,不在本文档约束范围内。

一、服务内容

G-Tunnel 提供内网穿透服务:由托管中转在你的客户端与发布端点的访问者之间转发流量。我们提供免费与付费套餐,资源配额(主机前缀数、TCP 端口数、带宽)各不相同。服务按"尽力而为"原则提供,免费套餐不承诺可用性(SLA)。

二、账号与凭证

  • 你对自身账号负责,并应妥善保管客户端凭证(ID / Secret);
  • 凡通过你的凭证创建的隧道转发的流量,均视为你的流量,无论是否由你本人发起;
  • 不得通过共享账号或凭证规避套餐配额或封禁措施。

三、可接受使用

你承诺不利用本服务发布、中转或传播以下内容:

  • 违反适用法律的内容或行为——包括钓鱼页面、恶意软件、僵尸网络控制端、垃圾信息与欺诈;
  • 涉及未成年人的色情内容(零容忍:永久封禁并依法上报);
  • 侵犯他人知识产权或其他合法权益的内容;
  • 通过本服务发起或中转的任何攻击行为(扫描、DDoS、爆破、漏洞利用);
  • 你无权对外暴露的服务(例如不属于你的第三方系统);
  • 其他我们合理认定对本服务、其用户或公众有害的滥用行为。

违规处理与举报方式见滥用举报政策。

四、资源公平使用

带宽、连接数与端点配额按套餐限制。长期占用量影响其他用户、对平台进行自动化批量扫描、或未经书面许可转售本服务的,我们可限速或暂停服务。

五、所暴露服务的责任

你对通过隧道暴露的服务与内容独自负责,包括其背后本地服务的安全防护,以及对你和访问者适用法律的合规义务。因你使用本服务引发的索赔,你同意向我们作出赔偿。

六、可用性与变更

我们可能随时修改、限制或中止部分服务。功能与配额调整一般会在网站上公告。app.gtunnel.dev 下的端点不保证不间断运行。

七、暂停与终止

你可随时停止使用本服务。对违反本条款的账号,我们可暂停或终止服务——对明确的滥用行为(钓鱼、恶意软件、违法内容)可不事先通知。你申请注销时,我们将删除控制台中的账号数据。

八、免责与责任限制

本服务按"现状"提供,不附带任何形式的保证。在适用法律允许的最大范围内,我们对因使用或无法使用本服务导致的间接、附带或后果性损害,以及数据丢失、营业中断不承担责任。本条款不排除法律不能排除的责任。

九、条款变更

我们可能更新本条款;现行版本始终发布于本页并标注更新日期。变更后继续使用即视为接受。

十、联系方式

条款相关问题:abuse@gtunnel.dev。滥用举报:见滥用举报政策。
